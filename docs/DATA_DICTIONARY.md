# Data dictionary

Nine tables, 56,787 rows, 104 complete weeks from Monday 2 September 2024 to
Sunday 30 August 2026. All of it generated by `scripts/generate_data.py` from
seed 2026, so the same run reproduces the same numbers exactly.

Grain first, because everything else follows from it.

| Table | Grain | Rows |
|---|---|---|
| `dim_date` | one row per day | 728 |
| `dim_sub_department` | one row per sub-department | 5 |
| `dim_product_group` | one row per product group | 14 |
| `dim_waste_reason` | one row per waste reason | 4 |
| `dim_role` | one row per role | 4 |
| `fact_sales` | day by product group | 10,192 |
| `fact_waste` | day by product group by reason | 39,288 |
| `fact_labour` | day by role | 2,912 |
| `fact_budget` | day by sub-department | 3,640 |

## dim_date

| Column | Type | Notes |
|---|---|---|
| `Date` | date | Primary key. Mark the table as a date table on this column. |
| `WeekStartDate`, `WeekEndDate` | date | Monday to Sunday, the retail week. |
| `WeekLabel` | text | `W/E 11 Jan 2026`. What goes on an axis. |
| `WeekIndex` | integer | 1 to 104. Sort key for `WeekLabel`. |
| `Year`, `MonthNumber`, `MonthName`, `MonthYear`, `MonthYearSort`, `Quarter` | | `MonthYear` sorts by `MonthYearSort`. |
| `FinancialYear` | text | Australian financial year, July to June. |
| `DayName`, `DayOfWeekNumber` | | `DayName` sorts by `DayOfWeekNumber`. |
| `IsWeekend`, `IsPublicHoliday` | boolean | |
| `HolidayName` | text | Blank on non-holidays. |

Victorian public holidays are computed, not typed in: Easter comes from the
anonymous Gregorian algorithm, Labour Day and the King's Birthday from an nth
weekday function, and weekend substitute days are applied to New Year's Day,
Australia Day, Christmas and Boxing Day. The Friday before the AFL Grand Final
is a Victorian public holiday but its date is set each year and cannot be
computed, so it is deliberately left out rather than guessed. 23 holidays fall in
the window.

| `WasteReason` | Primary key. Date code expiry, Quality reject, Damage, Prep & trim loss. |

than by what the label says, and ordering and rotation is the only bucket a
department manager fully owns.

| Column | Notes |
|---|---|
| `Date`, `RoleKey` | Composite grain. |
| `RosteredHours`, `ActualHours` | |
| `EffectiveHourlyRate` | Base rate times the penalty for the day. |

Penalty rates are 1.25 on Saturday, 1.5 on Sunday and 2.25 on a public holiday.
Plausible shapes, not real award rates.

## fact_budget

| Column | Notes |
|---|---|
| `Date`, `SubDepartment` | Composite grain. |
| `SalesBudget`, `WageBudget`, `WasteBudget`, `GrossProfitBudget` | |

Set weekly, then phased across the seven days on the trading profile. The budget
is deliberately naive: it follows the seasonal trend but ignores holiday timing
entirely, which is what makes the variance pages worth building. A budget that
already knew about Easter would leave nothing to explain.

## agg_weekly.csv

Written by `scripts/summarise.py`. Everything rolled to the 104 weeks with the
ratios precomputed. A flat file for anyone who wants the weekly numbers without
running the dashboard.

The ratio columns are computed per week and cannot be averaged to get a period
figure, because that weights a quiet January week the same as a Christmas week.
Sum the dollars and divide. The measures in `dashboard/measures.py` do this
correctly and this file does not, which is the reason it is a convenience rather
than the model.
